## Run locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Dataset
FiveThirtyEight `bad-drivers` dataset.
Raw CSV: https://raw.githubusercontent.com/fivethirtyeight/data/master/bad-drivers/bad-drivers.csv
Repository: https://github.com/fivethirtyeight/data/tree/master/bad-drivers

## Deploy on Streamlit Community Cloud
1. Put `streamlit_app.py`, `bad-drivers.csv`, and `requirements.txt` in the root of a GitHub repository.
2. Sign in at https://share.streamlit.io and create an app from that repository.
3. Choose `streamlit_app.py` as the entrypoint.
4. Pick a public `*.streamlit.app` subdomain and deploy.
